# Forgotten password

## Short answer

On the sign-in page, press **Forgot password? (Umesahau nenosiri?)**, type the email, and use the 6-digit code that arrives by email and by SMS to the business phone.

## Steps

1. Open the sign-in page and press **Forgot password? (Umesahau nenosiri?)**.
2. Type the email you sign in with and press **Send code (Tuma namba)**.
3. Look for the code:
   - in that email inbox, subject "Balce password reset code";
   - in an SMS to the **business phone** saved in **Settings → Business**.
4. Type the code and a new password of at least 8 characters, then press **Set new password (Weka nenosiri jipya)**.
5. Sign in with the new password. Other phones and computers are signed out.

## Common questions

- **No code came.**
  - Wait a minute and check spam.
  - Press **Send a new code (Tuma namba mpya)**. Only the newest code works.
  - The desktop app needs the internet to send codes.
- **"Too many" or no new code.** One person gets at most three codes an hour. Wait, or ask the owner.
- **A cashier forgot their password.** Their SMS goes to the business phone, so the owner receives it. The owner can also set a new password under **Users (Watumiaji)**.
- **The owner forgot and the business phone is wrong.** The code still arrives by email. If neither works, the Faltasi team can reset the password from the admin panel (online shops).
- **"The code is wrong or has expired".** Codes last 15 minutes, and five wrong tries end a code. Ask for a new one.
